One-page site. Four keepers only.

Repo: https://github.com/rankbotaiapp-byte/eric-mullen-portfolio

## You must fill in

1. `src/data/profile.ts` — `email` and `linkedin`
2. `public/resume.md` — same email

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

1. Vercel → Import `rankbotaiapp-byte/eric-mullen-portfolio`
2. Framework preset: Next.js
3. Put the Vercel URL on LinkedIn Featured and in `GITHUB_PROFILE.md`
